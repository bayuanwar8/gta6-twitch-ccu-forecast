Forecast GTA VI's launch-day Twitch concurrent viewers hour by hour. Reads the first hour's viewer count plus 14 days of history and 38 past big-launch curves, then forecasts hours 2-24 (UTC) as five quantiles each, using a weighted log-ratio diurnal model: each hour's viewers are predicted as a multiple of hour 1's count, with the multiple and its spread learned from comparable launches (console-only, single-player, rolling-midnight launches weighted most).

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
